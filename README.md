# Python Server
Python server with portable python by [Reyette](https://github.com/Zeev-x).This server can run on the go with USB Flash drive.

## Note
* Portable python only work on windows

## How to use (in windows)
* run ```install_portable_py.bat``` first
* and run your scripts with command ```pyr main.py``` or ```pyr your_script.py```
